# Action Step 01 — Repo scaffolding (P0.01)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

An installable, testable `kainos` Python package skeleton with a Makefile, gitignore,
and README — no logic yet.

## Prerequisites

- [ ] Repo root exists (`/home/jsmille/Projects/kainos-logos/`). Working dir = repo root.

## Background

Every later directive assumes: `pip install -e '.[dev]'` works, `import kainos` works,
and `make test/lint/typecheck/cli` are stable commands. Set them once, never change them.

## Steps

### 0. Docker image (ADR-0010 — do this first)

- Create `Dockerfile` (pinned base image digest) + a lockfile. Include: Python ≥3.11,
  `perl` (the regex judge), dev deps `pytest`/`hypothesis`/`mypy`/`ruff`, and `jsonschema`.
- Pin every version; no `:latest` tags. Add `.dockerignore` (exclude `results/`, `.git/`, `data/*.sqlite`).
- `Makefile` target `image` builds it; `test`/`lint`/`typecheck` run **inside** the container.
- **Verify:** `make image` builds; `docker run ... pytest -q` runs inside the image.

### 1. `pyproject.toml` — package `kainos`, `requires-python = ">=3.11"`, version
   `0.1.0`, with:
   ```toml
   [project]
   name = "kainos"
   version = "0.1.0"
   requires-python = ">=3.11"

   [project.optional-dependencies]
   dev = ["pytest", "hypothesis", "mypy", "ruff"]

   [build-system]
   requires = ["setuptools>=68"]
   build-backend = "setuptools.build_meta"

   [tool.setuptools.packages.find]
   where = ["src"]
   ```
2. **`src/kainos/__init__.py`** — empty except `__version__ = "0.1.0"`.
3. **`tests/__init__.py`** — empty (marks tests package).
4. **`.gitignore`** — `__pycache__/`, `*.pyc`, `.pytest_cache/`, `.mypy_cache/`,
   `*.sqlite`, `results/`, `data/*.sqlite`, `.venv/`, `dist/`, `*.egg-info/`.
5. **`Makefile`** — targets (tab-indented):
   ```
   test: ; python -m pytest -q
   lint: ; python -m ruff check src tests
   typecheck: ; python -m mypy src
   bench: ; @echo "bench: not wired yet (real runner arrives in step 05)"
   ```
   (`bench` is a **no-op placeholder** that succeeds; step 05 replaces the recipe
   with the real `kainos experiment run` wiring. Do not point it at a module that
   doesn't exist yet.)
6. **`README.md`** — two lines: project name + "see `plan/` for the plan, `action-steps/`
   for how to build it."

## Verification

```bash
pip install -e '.[dev]' && python -c "import kainos; print(kainos.__version__)" && pytest -q
```

Expect: install succeeds; prints `0.1.0`; `pytest` exits 0 (0 tests collected).
