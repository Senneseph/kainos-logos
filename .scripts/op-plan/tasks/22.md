## Goal

`kainos.workspace`: the recursive memory subsystem — WORKSPACE containers (bounded,
lifetime-scoped, nestable, queryable, forkable) plus **explicit, provenance-carrying
promotion** into the CODEX and versioned source/analysis separation. E3.7 runs green

## Prerequisites

- [ ] Phases 0–2 complete (steps 01–16): `kainos.codex` (assertions, provenance,
  status), `kainos.ir` (Semantic IR + codec) work; the claim registry knows **X3**

## Background

Memory in this architecture is **recursively addressable structure, not a bigger
context window** (P12). Intermediate representations are objects: they can be stored,
linked, interrogated, revised, forked, discarded — and they can contain other
workspaces ("analyze a 500-page document" = one child workspace per chapter). The
corruption path this step closes: working memory silently becoming "truth."

Two rules are non-negotiable (ADR-0012):

1. **Promotion is explicit and provenance-carrying.** `workspace.promote(ir)` writes
   the IR's relationships as **candidate** assertions with
   `provenance.source = workspace_<id>`; they then pass the ordinary Phase-2
   consolidation path before `established`. Nothing else writes a workspace's
   content to the CODEX.
2. **Un-promoted content is invisible to the CODEX.** A CODEX query must never
   return a fact that exists only in a workspace. This is the negative control in
   E3.7, and it must be part of the *result file*, not just a test.

Authoritative design: `plan/10-architecture/workspace-memory.md`. Experiment spec:
`plan/30-phases/phase-3-generalization/experiments.md` → E3.7.

**Scope guard:** local file sources only (uri + hash). No document ingestion, no
external fetches in Phase 3.

## Steps

### 1. `src/kainos/workspace/workspace.py`

```python
class Lifetime(str, Enum):
    EPHEMERAL; SESSION; PROJECT; LONG_TERM

@dataclass
class WorkSpace:
    id: str
    label: str
    lifetime: Lifetime = Lifetime.SESSION
    parent: "WorkSpace | None" = None
    irs: dict[str, dict] = field(default_factory=dict)      # role → Semantic IR (dict)
    children: dict[str, "WorkSpace"] = field(default_factory=dict)

    def add_ir(self, ir: dict, role: str) -> None
    def add_child(self, child: WorkSpace) -> None
    def query(self, predicate) -> list[dict]   # BFS over self + descendants' IRs
    def fork(self, new_id: str) -> WorkSpace   # deep copy of this workspace (new id)
    def dump(self) -> dict                     # deterministic JSON (ridable codec)
    @staticmethod
    def load(data: dict) -> WorkSpace
```

- `query` walks the relationship fields (`subject`/`relation`/`object`) of every
  contained IR at every depth; a decision stored in a grandchild must be found from
  the project root.
- `fork` = deep copy (fork-then-revise is the workflow); the fork is a *separate*
  workspace with its own id — mutations must not leak to the original.
- `dump`/`load` are byte-deterministic (seeded key order) so a workspace round-trips
  through JSON without loss (this is how a session restarts).

### 2. `src/kainos/workspace/source.py`

```python
@dataclass
class SourceRef:
    uri: str; hash: str; version: int = 1

@dataclass
class AnalysisRecord:
    source_id: str; version: int; ir: dict; created_at: str

class SourceRegistry:
    def register(self, ref: SourceRef) -> None
    def add_analysis(self, source_id: str, ir: dict) -> AnalysisRecord
        # versions are immutable + append-only: re-analysis NEVER overwrites
    def latest_analysis(self, source_id: str) -> AnalysisRecord
    def stale_derivations(self, source_id: str, new_hash: str) -> list[str]
        # hash changed ⇒ every DERIVED_FROM(source) marker is stale
```

"What did we conclude last time?" = `latest_analysis`. "Re-analyze for
contradictions with the current model" = a new `add_analysis` call (a workspace
operation), output versioned `vN+1`.

### 3. `src/kainos/workspace/promote.py`

```python
def promote(workspace: WorkSpace, ir_role: str, codex,
            observer: str) -> list[str]   # assertion ids written
```

- For each relationship in the named IR: `codex.add(Assertion(...,
  status=EpistemicState.candidate,
  provenance=Provenance(source=Source(uri=f"workspace_{workspace.id}"),
  observer=observer, derived=True)))`.
- Idempotent: re-promoting the same relationship is a no-op (matches the delta-merge
  discipline from step 19).
- `def lapse(workspace: WorkSpace, sink: Path) -> None` — expired/abandoned
  lifetimes: dump to `sink` (results-class storage) or discard; **never** to the CODEX.

### 4. E3.7 runner

`run_e3_7()` (register as `e3.7` in `kainos.harness.runner.REGISTRY`), scripted per
the E3.7 spec:

- Build `PROJECT_GAME` (lifetime PROJECT) → child `WORLD` → grandchild `TRANSPORT`;
  record a transport-decision IR in the grandchild and a combat-decision IR in a
  sibling child `COMBAT`.
- **Query check:** from the project root, `query("transport")` returns the
  grandchild's decision (recursion ≥ 2) — no reprocessing of any "conversation."
- **Fork/revise:** fork `PROJECT_GAME`; in the fork, change the transport decision;
  `query` on the root still returns the original decision; the fork returns the
  revision. Latest-decision check uses fork state.
- **Promote:** `promote(fork, "transport_decision", codex)` → candidate assertions
  with `source = workspace_<fork_id>`; assert via `codex.query(relation="located_at")`
  (or the decision's relation) that they appear **as candidates**.
- **Negative control (mandatory, in the result file):** pick an IR that was *never*
  promoted; assert zero CODEX assertions match it. Record
  `negative_control_passed: bool` in the JSON.
- **Source check:** a local file source with two analyses; latest = v2; change the
  simulated hash ⇒ `stale_derivations` flags the derived markers.

Write `results/phase-3/e3.7.json`:
`{config, query_accuracy, recursion_depth, fork_isolation, promotion:
{assertion_count, status, source}, negative_control_passed, source_versioning}`.

### 5. Tests

- `tests/workspace/test_workspace.py`: recursion ≥ 2 (grandchild queryable from
  root); fork isolation (mutation doesn't leak); dump/load round-trip is
  lossless + deterministic.
- `tests/workspace/test_promotion.py`: promote → candidates only (status asserted),
