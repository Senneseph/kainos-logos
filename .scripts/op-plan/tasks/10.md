# Action Step 10 — Compositional set + E1.2 (P1.10–P1.11)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

Prove compositional generalization (C1): the pipeline solves **novel combinations** of
known operators — combos that never appeared together in the seed corpus — and beats a
no-CODEX baseline.

## Prerequisites

- [ ] Steps 06–09 done (E1.1 parity == 1.0).

## Background

This is the core architectural claim. A conventional system that memorized the seed
data should *fail* on unseen operator combinations; the IR+CODEX pipeline should
*succeed*, because it composes known abstractions rather than recalling whole patterns.

## Steps

### 1. `src/kainos/regex/compose.py`

`generate_compositional_set(seed_corpus, n=40, seed=42) -> list[dict]`
- Take a cross-product of operators (e.g. `three digits` + `optional` + `hyphen` +
  `two letters`) and build descriptions that **no single seed record** contains.
- Each output record: `{id, description, expected_pcre, positive, negative}` with
  `expected_pcre` verified by the judge (so the set is ground-truthed).
- **Assert no duplicate** of a seed description (compare normalized descriptions).
- **Materialize** the ground-truthed set to `data/regex/compositional_set.jsonl`
  (committed; deterministic under seed 42). It must be an on-disk artifact, not an
  in-memory-only object, so E1.2 and the E1.5 hold-out are auditable and reproducible
  (G2).

### 2. Baseline (no CODEX)

`src/kainos/regex/baseline.py` — `DirectBaseline`: kernel → emitter with **hard-coded**
class/literal meanings (no resolver/CODEX). It can't resolve `UnresolvedRef` and will
fail on anything the seed grammar didn't hard-code. This isolates the CODEX's
contribution (it's the "Model A" stand-in for the deterministic comparison; the full
LLM A/B is step 12).

### 3. E1.2 runner

`run_e1_2()`: run pipeline vs `DirectBaseline` on the compositional set; write
`results/phase-1/e1.2.json` with `{pipeline_accuracy, baseline_accuracy, margin}`.

## Verification

```bash
kainos experiment run --name e1.2 && python -c "import json;d=json.load(open('results/phase-1/e1.2.json'));print(d['pipeline_accuracy'], d['baseline_accuracy'])"
```

Expect: `pipeline_accuracy ≥ 0.8` **and** `pipeline_accuracy ≥ baseline_accuracy + 0.1`.
