# Action Step 16 — E2.1–E2.5 runs + Phase 2 sign-off (P2.10–P2.15)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

Run the five Phase 2 experiments (active acquisition, EXCEPTION shrinkage, persistent
growth, compositional recognition, contradiction→dimension) and sign off Phase 2.

## Prerequisites

- [ ] Steps 13–15 done.

## Background

These five experiments are the *whole point* of the 20Q phase. Each is falsifiable
and reported through the harness. E2.3 (persistence) and E2.5 (contradiction) matter
most for the project thesis.

## Steps

### 1. Runners (register each in the harness registry)

- `run_e2_1()`: ≥500 games system vs `RandomQuestioner`. Metrics: median
  questions-to-solve, win-rate. → `results/phase-2/e2.1.json`. Threshold: system
  median ≥20% fewer and win-rate ≥ baseline.
- `run_e2_2()`: long game sequence; sample `Coverage` + exception counts every K games;
  trend → `results/phase-2/e2.2.json` + `growth.md`. Threshold: coverage ↑, exceptions ↓.
- `run_e2_3()`: split corpus → train set 1 → dump CODEX → restart → play set 2.
  Ablation: no-CODEX control. → `results/phase-2/e2.3.json`. Threshold:
  with-persistence < without-persistence.
- `run_e2_4()`: hold out labels for a subset (properties still learned) → measure
  inference. → `results/phase-2/e2.4.json`. Threshold: accuracy ≥ 0.7.
- `run_e2_5()`: inject bear/polar-bear hibernation conflict → run learning loop →
  assert new context TERM. → `results/phase-2/e2.5.json`. Threshold: ≥1 new TERM; both
  assertions retained; disputed count → 0 for that pair.
