# Action Step 03 — CODEX explain + Semantic IR codec (P0.04–P0.05)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

(a) `explain(assertion_id)` returns an assertion with its evidence chain (inspectability);
(b) a versioned Semantic IR with JSON-Schema validation and a codec.

## Prerequisites

- [ ] Step 02 done (`kainos.codex` works, disputed-pair test green).

## Background

Inspectability is a first-class feature (invariant #9): every conclusion must expose
its trace. The Semantic IR is the JSON-serializable, versioned structure all layers
speak (invariant #7) — it must be validated at every boundary so a malformed IR can't
silently corrupt downstream reasoning.

## Steps

### 1. `src/kainos/codex/explain.py`

```python
def explain(store, id: str, depth: int = 3) -> dict:
    """Return assertion dict + provenance + evidence chain (recursive, depth-limited)."""
```

- Resolve the assertion; include its `provenance`; for each id in
  `provenance.evidence`, recurse (up to `depth`) and collect a `chain` list.
- Never raise on missing evidence — represent as `{"id": ..., "missing": True}`.
- Wire `explain` into both store impls (`SqliteCodexStore.explain`,
  `InMemoryCodexStore.explain`) so the protocol's `explain` is satisfied.

### 2. `specs/ir.schema.json`

JSON Schema (draft 2020-12) named `kainos/ir/1` with:

- top-level `object`; required `["kind"]`; `kind` enum
  `["state","pattern","query","command"]`;
- optional arrays: `goals`, `entities`, `relationships`, `events`, `constraints`,
  `unresolved`, `hypotheses`; optional `meta` object;
- `entities[].id` required (string), `type` (string), `labels` (array of string);
- `relationships[]` required `subject`, `relation`, `object` (strings), optional
  `context` (object);
- `constraints[]` required `kind` (string), optional `value`;
- `unresolved[]` required `id`, `surface`, optional `candidates` (array of string).

### 3. `src/kainos/ir/models.py`

`SemanticIR` (a thin wrapper over the validated dict) + small dataclasses
`Entity`, `Relationship`, `Constraint`, `UnresolvedRef`, `Hypothesis`, `Goal` — each
with `to_dict/from_dict`. Keep them minimal; the schema is the source of truth.

### 4. `src/kainos/ir/codec.py`

```python
def validate(data: dict) -> None          # raises ValueError with schema path on failure
def load(data: dict) -> SemanticIR        # validate + wrap
def dump(ir: SemanticIR) -> dict          # unwrap (deterministic)
```

- Use `jsonschema` (add `jsonschema` to dev deps if not present).
- Bundle `specs/ir.schema.json` with the package (via `importlib.resources`) so
  `validate` doesn't depend on CWD.

### 5. Tests

- `tests/codex/test_explain.py`: seed two assertions where B is evidence for A; assert
  `explain(A)` includes B in its chain; assert a missing evidence id doesn't raise.
- `tests/ir/test_codec.py`: a valid sample loads; a dict missing `kind` raises with a
  schema path in the message; `dump(load(x)) == x` for a fixture.
- Add `tests/ir/golden/minimal.json` — a minimal valid state IR committed as a fixture.
