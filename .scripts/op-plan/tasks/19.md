# Action Step 19 — Distributed CODEX: exchange + reconciliation (P3.06–P3.08)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

Two CODEX nodes exchange assertion deltas and reconcile a contradiction
("X" vs "NOT-X") by discovering a missing dimension — producing a higher-order TERM
instead of a blended weight.

## Prerequisites

- [ ] Phase 2 done (the single-node learning loop's reconciliation primitives exist).

## Background

The exchange unit is a **semantic transaction** (assertion + provenance), never a raw
mutation. Merge preserves conflicts (invariant #6); the reconciler turns a recurring
contradiction into ontology expansion. This is the distributed form of the single-node
EXCEPTION→dimension mechanism.

## Steps

### 1. `src/kainos/exchange/protocol.py`

- `AssertionDelta` message schema (JSON): `{assertion, node_id, timestamp}`.
- `merge(a_store, deltas) -> MergeReport`: add assertions, **preserving** both sides of
  any conflict (set `status=disputed`, link evidence). Idempotent (re-merging the same
  delta is a no-op).

### 2. `src/kainos/exchange/reconciler.py`

`reconcile(store, subject, relation) -> Reconciliation`:
- collect conflicting `established` assertions (`X` vs `NOT-X`);
- enumerate candidate dimensions (`time, location, role, modality, context`);
- if a dimension explains both, create a **new context TERM** and re-express both
  assertions under distinct contexts; else leave as `disputed`.

### 3. E3.3 two-node demo

`run_e3_3()`: node A learns `X`; node B learns `NOT-X`; exchange + reconcile.
→ `results/phase-3/e3.3.json`. Threshold: ≥1 new context TERM; both assertions
`established` under distinct contexts; `disputed` count → 0 for that pair.

### 4. Tests

- `tests/exchange/test_merge.py`: merge keeps both sides; idempotent; provenance preserved.
- `tests/exchange/test_reconciler.py`: bear/polar-bear hibernation → new context TERM;
  both assertions `established`; no averaging.

## Verification

```bash
pytest tests/exchange -q && kainos experiment run --name e3.3
```

Expect: merge/reconciler tests green; E3.3 thresholds met.
