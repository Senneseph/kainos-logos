# Action Step 11 — Persistent memory + honest uncertainty (P1.12–P1.13)

> Self-contained: you need only `00-CONTEXT.md` + this file.

## Goal

Two demonstrations: (C2) a CODEX entry survives a full restart and is reused with
frozen neural weights; (C3) underspecified input is recognized and escalated, never
hallucinated.

## Prerequisites

- [ ] Steps 06–10 done.

## Background

C2 is the emotional center of the whole project: knowledge separated from weights.
C3 is the "when should the AI stop pretending it knows?" behavior. Both are what make
this *not* just another regex generator.

## Steps

### 1. Persistent-memory teaching (C2)

- Teach the CODEX: `US_PHONE_NUMBER --realizes_as--> "\d{3}-\d{3}-\d{4}"`
  (provenance `Source(uri="user_instruction", version="1")`, `status=established`).
- `describe("an American phone number")` → succeeds (kernel has no rule for
  "phone number"; the resolver finds it via CODEX).
- **Restart:** dump CODEX to disk → construct a *fresh* pipeline (same kernel code,
  reloaded CODEX) → `describe` again → succeeds.
- Test `tests/regex/test_persistence.py` asserts both runs pass and `explain` shows
  the provenance.

### 2. Vague-set + escalation (C3)

- `data/regex/vague_set.jsonl`: ~10 deliberately underspecified descriptions
  ("…then the dash thing…", "start with the number thing, three of them…").
- Run pipeline; for each, expect either (a) resolved via rotation, or (b) escalation
  (`recommended_action == "ask_human"`), and **never** an unjustified regex.
- Metrics: `clarification_rate = escalated/total`, `justified_rate = (emitted with
  complete trace)/emitted`.

### 3. E1.3 / E1.4 runners

- `run_e1_3()` → `results/phase-1/e1.3.json` (`before`, `after`, `assertion_present`).
- `run_e1_4()` → `results/phase-1/e1.4.json` (`clarification_rate`, `justified_rate`).
- Register `e1.3`, `e1.4` in the harness registry.

## Verification

```bash
pytest tests/regex/test_persistence.py -q && kainos experiment run --name e1.4 && python -c "import json;d=json.load(open('results/phase-1/e1.4.json'));print(d['clarification_rate'], d['justified_rate'])"
```

Expect: persistence test green; `clarification_rate ≥ 0.5` and `justified_rate == 1.0`.
