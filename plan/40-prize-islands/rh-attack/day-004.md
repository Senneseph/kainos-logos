## 2. The missing-term experiment (the owner's question, measured)

"Does the series need the previous/next terms in relation to the current?"
Measured with the full engine stack (CPU EM zeta + GPU-batched partial sums;
`day004_missing_terms.py`, `day004_missing_terms_N.py`):

**THE LAW (measured to 3–5 digits, CPU = GPU agreement):** for
s = σ + it and the N-term zeta series, the missing tail is

```
    |zeta(s) - P_N(s)|  =  N^{1-sigma} / |1-s|      (exact at measured precision)
```

- N = 10⁴, t = 0: tail = 20.00 at N = 10⁴ = 2·100 = 2√N exactly (row: 20.05,
  63.26, 200.00, 632.46… with tail/√N = 2.00000).
- t = 50: tail/√N = 0.02000 = 1/|1−s| (row exact to 5 digits).
- t = 990 (both at a zero and between zeros): tail/√N = 1/990 to 5 digits
  for N ∈ [10⁴, 10⁷].

**The first-order "next term" is the negative of the integral** — measured as a
vector identity, grid-wide (7 t-rows × 111 σ): `T1 = |T0_vec − I|` with
`I = N^{1-s}/(1-s)`:

| regime (fixed N = 10⁴) | T1/T0 | meaning (measured) |
|---|---|---|
| t ≤ 10³ (incl. zero rows γ₁, γ₂, between) | **2.000** | missing tail = −I EXACTLY (size and complex direction): the "next term" is fully determined, phase included |
| t = 5×10⁴ | 0.821 | second-order (zero-oscillation) terms become comparable to the first order |
| t = 10⁵ (at a 1e5-list zero) | 1.000 | first order is 10⁻³ of the tail; the tail IS the higher-order structure |

And after subtracting the true first order at t = 0, the **second order is
the half-endpoint term** (measured to 4 digits): remainder = 1/(2√N):
0.0500, 0.0158, 0.0050, 0.0016 for N = 10²…10⁵ = −½·N^{−s} + …
(the second 1/2, in the series' own tail hierarchy).

**The 1/2, located (measured):** the boundary where the bare series stops
working is σ = 1 (not 1/2); the 1/2 is the **growth exponent**: on the
failing side, σ < 1, the error after N terms grows as N^{1−σ} — at the line
σ = 1/2 that is **√N = N^{1/2}**: the missing block relative to the current
last term has size N^{1/2}/|1−s| / N^{−1/2} = N/|1−s| ≈ N·(1/t) at the line:
**the tail is ~N/t times the current term** (e.g. N = 10⁷, t ≈ 990: 3.19 vs
3.2e-4 → 10,000×). The Riemann–Siegel continuation is the only mechanism that
beats this (12.6 terms at t ≈ 990 where the naive series needs none — it
never converges for σ ≤ 1).

**Zeros and the missing tail (measured):** the zero rows and between-zeros rows
are identical in the first-order profile (no resonance): **the first-order
"next term" −I(s) is a smooth function that does not see the zeros; the zeros
enter at second order**, in the regime t ≳ ~5N (measured onset between
t = 10³ and 5×10⁴ at N = 10⁴ — flagged for Day-005 refinement; that second
order is exactly where the criterion gap x^{1/2} vs x^{1/2+ε} lives).

**Protocol defects caught by cross-check (discipline note):**
1. v1 of the σ-grid (`day004_missing_terms.py`) silently computed Σ n^{−σ}
   without the oscillating n^{−it} factor — its rows were t-independent.
   Caught because independent E1b (with the factor) disagreed by 1700× at the
   same (s, N). Fixed and re-run; the two experiments now agree with each
   other AND with the analytic law (mutual verification).
2. E1b v1's CPU "reference" block-sum had an off-by-one that dropped n = 1
   (constant 1.0 offset in every difference) — caught by comparing the two
   independent sums against each other; the dot-product values were the true
   ones (CPU = GPU agreement confirmed).
