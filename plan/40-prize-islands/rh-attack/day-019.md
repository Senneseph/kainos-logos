RCLike field 𝕜 and f : ℝ → 𝕜 twice differentiable on [n, m]:**

```
∑ k ∈ Ioc n m, f k
  = ∫_n^m f  +  ½ (f m − f n)  +  (1/12)(f′ m − f′ n)
```

   (`simpa using hj` bridges, probed) — so the hint lambda is
   `fun j hj => hIB1 j (by simpa using hj)`. (Also: `Finset.Ico 0 2`

   probe file had to write `(0 : ℕ)`.)

   (works in both directions, probed); `rw [← Nat.cast_one, ←
   Nat.cast_add]` only works after knowing which side is which form —
   and the real literal `1` is OfNat, not defeq to `↑(1 : ℕ)`, so the
   `← Nat.cast_one` pre-step is mandatory for the rw route. The
   endpoint-inequality proof uses the robust
