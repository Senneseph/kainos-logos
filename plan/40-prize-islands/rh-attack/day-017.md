## 3. The wall that day-017 was actually fighting (and its resolution)
Atom-2 started red (p4t15: **7 errors**). Every error was the *same* root
cause: **rational-constant normalization in a generic `[RCLike 𝕜]`** — the
finite/derivative EM machinery is machine-checked, but scalars 1/6 and 1/2
are *opaque* to `ring`/`norm_num`/`norm_cast`/`simp` when they appear as
`algebraMap ℝ 𝕜`-form (real-scalar) terms rather than natCast `𝕜`-form.
Three distinct sub-problems, each resolved with a targeted bridge
(then the residual closed by `ring`):

| sub-problem | residual shape | validated bridge |
|---|---|---|
| `hkr` (pointwise kernel `u x = (B̂₂ x : 𝕜)`) | polynomial parts match; `6⁻¹` vs `((algebraMap ℝ 𝕜) 6)⁻¹` | `have h6 : ((algebraMap ℝ 𝕜) 6) = (6 : 𝕜) := RCLike.ofReal_natCast 6; rw [h6]; ring` |
| `heq` (a.e. interior `u'·f′ = (2 B̂₁)·f′`) | `True ∨ deriv f x = 0` (ring artifact) | split into scalar `hupB1` (no deriv-f factor) + trivial factor step; `hupB1` via the 1/2 real→𝕜 bridge + `have hE : RCLike.ofRealCLM x = (x : 𝕜) := by rfl; rw [← hE]; ring` |
| two `calc` ½-closers | `(1/2 : 𝕜)` vs `((algebraMap ℝ 𝕜) 2)⁻¹` (the `real_smul_eq_coe_mul` coe form) | `have hhalf : (1/2 : 𝕜) = ((algebraMap ℝ 𝕜) 2)⁻¹ := by rw [show ((algebraMap ℝ 𝕜) 2) = (2 : 𝕜) from RCLike.ofReal_natCast 2; norm_num; simpa [hhalf] using RCLike.real_smul_eq_coe_mul (1/2 : ℝ) _` |

Key reusable facts pinned for this Mathlib 4.33.1 checkout:
- **`RCLike.ofReal_natCast (n : ℕ) : ((n : ℝ) : K) = n`** (tagged
  `@[rclike_simps, norm_cast]`; impl. `map_natCast (algebraMap ℝ K) n`) is the
  single-tool that bridges `(algebraMap ℝ 𝕜) n` ↔ `(n : 𝕜)`. Direct
  `rw [ofReal_natCast]` fails (it matches the `↑` cast form, not the
  algebraMap-application form) — but `have h : ((algebraMap ℝ 𝕜) n) = (n : 𝕜)
  := RCLike.ofReal_natCast n; rw [h]` works, because the two forms are
  *definitionally* equal (verified by `rfl`).
- **The 1/2 real→𝕜 bridge** (real `1/2` is `HDiv`-form, not `Rat.cast`-form, so
  `ofReal_ratCast` needs a `norm_num` pre-rewrite):
  `have hcast : ((1/2:ℝ):𝕜) = (((1/2:ℚ):ℝ):𝕜) := by rw [show (1/2:ℝ) = ((1/2:ℚ):ℝ) from by norm_num]; rw [hcast, RCLike.ofReal_ratCast (1/2:ℚ)]; norm_num`.
- **`RCLike.ofReal_{add,sub,mul,neg,intCast,ratCast}`** are all
  `@[rclike_simps, norm_cast]` (Basic.lean ~177–200, 604, 624) — `norm_cast`
  pushes `algebraMap` into real polynomials for free.
- `ring` treats `RCLike.ofRealCLM x` and `(x : 𝕜)` as *distinct atoms* — unify
  them with `have hE : RCLike.ofRealCLM x = (x : 𝕜) := by rfl; rw [← hE]`
  before the final `ring`.
- In this Lean version, `rw` auto-closes a resulting reflexive goal — avoid a
  redundant trailing `rfl`.

None of these are mathematical walls: the 1859/EM identities are textbook and
were numerically verified day-017 at σ=1.5 [3.2e-7] and σ=½ [3.7e-5] (mpmath
dps-40, computed not recalled). This is a *formalization* friction specific to
doing scalar calculus in an abstract field via `RCLike`, and it is now broken
through with pinned, reusable bridges.
