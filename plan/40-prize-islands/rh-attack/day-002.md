## 3. The owner's four mirrors — adjudicated (owner input, day 2)

The note: multiplying by an *i* operator should not be treated as one single mirror —
the x-y plane cycle is `x→−x, then y→−y, then x→+x, then back`: four reflections.

**Verdict: the COUNT is exactly right; the mechanism is two independent reflections, not
one rotation.** The zero set of any real-coefficient L-function with a functional
equation is invariant under the **Klein four-group** (symmetries of the rectangle centered
at (1/2, 0)):

```
id  : (σ, t) -> (σ, t)
C   : (σ, t) -> (σ, -t)      (complex conjugation — flips "y")
M   : (σ, t) -> (1-σ, -t)    (FE mirror — point-flip about (1/2, 0): the "x-then-y" step)
C*M : (σ, t) -> (1-σ, t)     (reflection in the line σ = 1/2)
```

Every zero thus has **up to four mirror slots**: itself, C, M, C*M. Measured (M6):

| zero type | orbit | measurement |
|---|---|---|
| on-line zero (RH) | 4 slots COLLAPSE to 2 on-axis points (γ and −γ); M and C coincide, C*M = id | all 4 slots ∼ 1e-15 (zeros) at γ = 14.13, 21.02, 25.01, 30.42 |
| off-line zero (RH violated, FE-consistent) | full **quartet** at 4 distinct points symmetric about the line | structural (no such zero known; the shape one would have to see) |
| leaked zero (broken mirror) | **half-orbit**: {s0, s̄0} full; {1−s̄0, 1−s0} empty | 2 FULL + 2 EMPTY, empties at 0.569255 (M4/M6, dps-50) |

And the literal cyclic *i*-rotation the note suspects is **measured ABSENT**: rotating
(1/2, γ1) by ±90° about (1/2, 0) lands at ∓13.63 + 0i and 14.63 + 0i with
|ζ| = 7.46e-2 and 1.000039 — not zeros. The four-fold structure is a product of mirrors
(Klein four), not i² = −1.

**Arithmetic echo (observed, not claimed):** 4 = 2² = "1/2 squared" — the same 4 that
