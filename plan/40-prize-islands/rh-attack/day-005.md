## 3. The χ₅ missing-term law — measured in Python, re-measured in TypeScript

The owner's fusion question asked where the Fibonacci primitive-prime bands
live analytically. They live in `L(s, χ₅)` — and the missing-term experiment
run on ζ (Day-004) has a character analogue that was measured today
(`day005_law_chi5.py`, reference L₅ by 5-period blocks to n = 2.5e7,
float64 convergence ~1e-11):

```
Σ_{n>N} χ₅(n) n^{-s} = −A(N) N^{-s} + (2s/5) N^{-s-1} + O(N^{-s-2}),   s = ½ + it
```

where `A(N) = Σ_{n≤N} χ₅(n)` is the periodic residue (N mod 5 ∈
{0,1,2,3,4} → {0, 1, 0, −1, 0}).

- The pole-side integral I of the zeta law is **replaced by a bounded
  discrete band-residue** — the "band" structure is literalized in the tail.
- Raw per-decade decay at A(N) = 0 points: exactly 31.62 = 10^{1.5}.
- After removing `A(N)N^{-s}`, the exponent is −1.492 (t=1) … −1.30 (t=1e4).
- Measured coefficient c(t) vs predicted |2s/5| = (2/5)√(¼ + t²):

| t     | 1     | 10    | 100    | 1000  |
|-------|-------|-------|--------|-------|
| c meas (python) | 0.4471 | ~4.00 | ~40.0  | ~400  |
| c meas (TS)     | 0.4481 | 4.0033 | 40.0124 | 404.19 |
| (2/5)·√(¼+t²) | 0.44721 | 4.0050 | 40.0005 | 400.00 |

The coefficient tracks the prediction to ~1% for t ≤ 1000 — the χ₅ law is
the same missing-term mechanism, thinned, with the pole term replaced by the
discrete band residue.

**TypeScript re-measurement** (`run-law-chi5.ts`): independent summation
order (block form vs sequential), independent float64 stack. Cross-checks vs
the python baselines — 4/4 PASS:
`c(1) = 0.4481 (0.4471 baseline ±2e-3)`; `c(t) tracks |2s/5| to 2% at every
measured t` (worst case 1.05%, t=1000); `raw two-decade ratio 992.5 (expect
1000 ±20)`; `corrected exponent −1.498 (expect −1.5 ±0.05)`. Runtime 0.5 s.

## 4. Fibonacci primitive-prime band density — both stacks agree

`B(n) = Σ 1/q` over the primitive prime divisors q of F_n (order of φ mod q
exactly n; Zsigmondy exceptions n = 6, 12 → B = 0; the degenerate primes
2, 5 excluded — 5 ramifies in Q(√5), 2 degenerates the field).
S(N) = Σ_{n=3..N} B(n).

Python baseline (`day005_band_density.py`): S(10) = 0.70285, S(20) = 0.90405,
S(100) = 1.26539; fit S ~ N^0.24; B(9) = 1/17; n = 100: F_100 has 9 distinct
factors, 2 primitive, B = 2.4955e-3.

**TypeScript re-measurement** (`run-band-density.ts`): bigint fast-doubling
Fibonacci, trial division + Pollard-rho factorization, exact-order test via
modulo Fibonacci — 7/7 cross-checks PASS:
`S(10) = 0.702846 (±5e-5)`; `S(20) = 0.904051 (±5e-5)`; `S(100) = 1.265391
(±2e-4)`; `B(9) = 1/17 to 1e-12`; `B(6) = B(12) = 0`; `fit exponent 0.2529
(expect 0.2429 ±0.015)`. Runtime 1.3 s.

Verdict so far: S(N) is **sub-logarithmic power growth** (a ≈ 0.24–0.25 over
2 decades of n) — the bands thin faster than 1/ln n, but do not saturate in
the measured range. A longer baseline (n → 10³–10⁴ in TS, now cheap) is
queued.

**The bug census — the motivation for the directive, made visible.**
The first single-file draft of the number-theory stack contained **7 latent
bugs**, all caught by the gates before any composition ran:

1. `fib(1)` base case: `(1,1)` vs `(1,2)` (the day-005 python twin).
2. `F(n)` read from the wrong slot of the `(F_n, F_{n+1})` pair (same class).
3. `fibModulo` bit scan: dropped the leading bit and could not represent
   "zero bits remain" — wrong F_n mod p for a whole parity of inputs.
4. `eulerPhiOf` tail: subtracted the *updated* value instead of the
   decrement — φ(p) = 1 for a prime p.
5. A "43-digit prime" test golden that was **composite** (2^113 − 1;
   smallest factor 79615056208375) — a recalled constant, not a computed one.
   Caught by running the test, replaced by a python-MR-verified 44-digit
   probable prime (42 bases).
6. Number-theoretic convention: the order criterion must exclude the
   degenerate primes {2, 5} — not {2, 3, 5}. S(10) came out exactly
   0.3333 = 1/3 low, and the Zsigmondy rows pinned which prime.
7. **Type-level**: `number[]` return for divisors silently loses precision
   for primes > 2^53 (F_100 has 21-digit factors). The whole divisor
   pipeline is now `bigint`; only the 1/q reciprocal crosses to double, at a
   measured ~1e-16 relative per term.

Items 3–5 are exactly the failures of *silent* arithmetic that the 1e6
S-walk twin incident made concrete: nothing throws, the number just lands 38
zeros off. Types + golden cross-checks + per-module unit tests are the
mechanism that makes that class fail loudly. Two of the seven (1, 2) recurred
verbatim from the python draft — the bugs were in the *thinking*, which is
why the tests are computed from an independent python implementation, not
copied from it.

**Golden cross-validation rule** (now standing): every TS measurement runner
asserts against independently-produced python goldens at the runner level
(not just module level), and reports each cross-check PASS/FAIL with the
measured value. Both runners: 0.5 s and 1.3 s, all cross-checks PASS.

## 8. Five-phase width table c_r(s) — the Lebesgue-cell cross-section, closed (day-006 prep, ran CPU-only while the 1e7 walk used the GPU)

The χ₅ missing tail, with r = N mod 5:

```
L(s, chi_5) - P_N(s) = -P(r) N^{-s} + c_r(s) N^{-s-1} + O(N^{-s-2})
```

measured in **two stacks** (dps-40 mpmath oracle via the exact Hurwitz-zeta
closed form L = 5^{-s}Σ_j χ(j)ζ_H(s, j/5), at N = 1e4 + r and 1e5 + r for
convergence; float64 TS `run-law-chi5-phases.ts` at N = 1e4 + r against those
goldens — **22/22 cross-checks PASS**, residuals 1.4e-5..1.3e-2 = exactly the
O(N^{-1}) asymptotic drift, phase-independent):

| r | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| c_r(s) = | +2s/5 | +2s/5 | **-3s/5** | **-3s/5** | +2s/5 |
| |c_r|, t=1 | 0.44721 | 0.44728 | 0.67077 | 0.67087 | 0.44715 |
| |c_r|, t=10 | 4.00500 | 4.00560 | 6.00705 | 6.00795 | 4.00440 |
| |c_r|, t=100 | 40.0038 | 40.0098 | 60.0000 | 60.0090 | 39.9978 |

Reading (measured; the closed forms follow to 5+ digits):

1. **The table takes exactly two values**: c_r = +2s/5 for r ∈ {0,1,4},
   c_r = −3s/5 for r ∈ {2,3}. b/a = −3/2 exactly (|·| ratio 1.50000, arg
   offset −π). The phase table is a *second* cell function, distinct from the
   band residue P(r) = (0,1,0,−1,0).
2. Both coefficients are **rational multiples of s** — the first width term
   is linear in s (weight 1), as the Euler–Maclaurin cell-moment structure
   requires.
3. The day-5 single-phase law (c = 2s/5, 4 digits) is the r = 0 row; **three
   of the five phases are new**. The t = 1000 "1.05% drift" from day 5 is
   *dissolved*: the oracle shows the identical O(N^{-1}) convergence (403.36
   at N=1e4 vs 400.03 at N=1e5) — the law does not break at t = 1000, the
   asymptotic just needs bigger N there.
4. Connection to the onset (section 1 + wiki): the measured onset curve C/|I|
   = ½(t/N) to 4 digits is the r-dependent width expansion in action — the
   half-term 2s/5-weighted cell structure is what the onset "sees".
